## How I work

- Evidence integrity beats test passage — fail closed rather than inject fabricated values.
- Verification is structural, not ceremonial: mutation-verified regression tests, attested base/head pairs, stated limits on every check.
- Preregistration is a structural defense: hypotheses, seeds, and analysis boundaries are locked before an experiment opens.
- Historical failures remain evidence even when later revisions pass.
